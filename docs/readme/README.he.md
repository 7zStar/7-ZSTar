## למה ⁦7-ZSTar⁩

- **בלי “הצג אפשרויות נוספות”.** ב־⁦Windows 11⁩, ⁦7-ZSTar⁩ נמצא ישירות ברמה הראשונה של תפריט הלחיצה הימנית.
- **יצירת ⁦tar.zst⁩ בשלב אחד.** אפשר לדחוס תיקייה לקובץ .⁦tar.zst⁩, או לחלץ אותו, בשלב אחד, בלי שיישאר קובץ .tar בדיסק. ב־⁦7-Zip⁩ הרשמי אי אפשר ליצור .⁦tar.zst⁩, וחילוץ שלו מתבצע בשני שלבים, דרך קובץ .⁦tar.⁩
- **מהיר בערך פי ⁦10⁩ מ־⁦7z.⁩** בתיקיות פרויקט אמיתיות, דחיסה ל־⁦tar.zst⁩ הייתה מהירה פי ⁦10⁩ עד ⁦18.⁩

קובץ ⁦tar.zst⁩ יצא קטן ב־⁦15⁩ עד ⁦23%⁩ מקובץ zip, ולא איטי ממנו. פורמט ⁦7z⁩ עדיין מפיק את הקבצים הקטנים ביותר (קובצי ⁦tar.zst⁩ היו גדולים ב־⁦15⁩ עד ⁦27%⁩), אבל לקח לו זמן רב יותר. החילוץ ארך בערך אותו זמן בשלושת הפורמטים.

## הורדה

רוב המשתמשים ירצו את קובץ ה־`.msi` ל־⁦x64⁩ לכל המשתמשים, מדף [המהדורות](https://github.com/7zStar/7-ZSTar/releases/latest).

| | לכל המשתמשים `.msi` | למשתמש הנוכחי בלבד `-user.msi` | נייד `.zip` |
|---|---|---|---|
| נדרשות הרשאות Administrator (מנהל מערכת) | כן | לא | לא |
| תפריט לחיצה ימנית | רמה ראשונה ב־⁦Windows 11⁩ | התפריט הקלאסי (ב־⁦Windows 11⁩: תחת “הצג אפשרויות נוספות”) | אין |
| פריט בתפריט התחלה | כן | כן | לא |

כל אחת מהחבילות זמינה גם ל־⁦x86⁩ ול־⁦arm64⁩; בחרו את זו שמתאימה ל־Windows שלכם. ב־Windows של ⁦64⁩ סיביות ייתכן שבחבילות ⁦x86⁩ אין תפריט לחיצה ימנית, ובניות ⁦arm64⁩ עדיין לא נוסו על חומרה אמיתית. ⁦7-ZSTar⁩ מותקן לצד ⁦7-Zip⁩ הרשמי בלי להשפיע עליו.

**ייתכן ש־Windows יזהיר אתכם בפעם הראשונה.** הקבצים אינם חתומים דיגיטלית, ולכן SmartScreen עלול לעצור אותם (“Windows הגן על המחשב שלך”; ייתכן שתצטרכו להרחיב את האזהרה כדי לראות את *הפעל בכל מקרה*), וב־⁦Windows 11⁩ כשבקרת אפליקציות חכמה מופעלת, קובץ ה־`.msi` נחסם לחלוטין. בכל מהדורה יש קובץ `SHA256SUMS` שאפשר להשוות אליו את ההורדה. [הוראות ההתקנה](../install/INSTALL.he.md#חבילות-לא-חתומות-smartscreen-ובקרת-אפליקציות-חכמה) מסבירות איך, ומה לעשות לגבי בקרת אפליקציות חכמה.

**על תפריט הרמה הראשונה:** ב־⁦Windows 11⁩, חבילת ה־`.msi` לכל המשתמשים מוסיפה חבילה קטנה החתומה בתעודה בחתימה עצמית, ומגדירה אמון בתעודה הזו; זה מה ש־Windows דורש כדי לאפשר רמה ראשונה. ההסרה מסירה את שניהם. אם אתם מעדיפים שלא, התקינו עם `msiexec /i 7-ZSTar-<version>-<arch>.msi SPARSE=0`. החבילה נרשמת עבור החשבון שמריץ את תוכנית ההתקנה; חשבונות אחרים נרשמים בנפרד.

שיוכי קבצים, הסרת ההתקנה והחבילה למשתמש הנוכחי בלבד מוסברים ב[הוראות ההתקנה](../install/INSTALL.he.md).

## שורת פקודה

```
7z a -ttar.zst backup.tar.zst docs
7z x backup.tar.zst -oout
```

ב־PowerShell יש לשים את המתג במרכאות: `7z a "-ttar.zst" backup.tar.zst docs`. בלעדיהן PowerShell מפצל אותו לשניים ומתקבל קובץ בשם `.zst`. ב־Command Prompt (cmd) אין צורך במרכאות.

## כדאי לדעת

- **כיבוי האפשרות “`אל תפריט ההקשר של המעטפת Zip7 שלב את`”** (במנהל הקבצים, **כלים > …אפשרויות > ⁦7-ZSTar⁩**) מסיר את הפריט מתפריט הלחיצה הימנית, כמו ב־⁦7-Zip⁩ הרשמי. עם החבילה לכל המשתמשים אפשר להפעיל אותה מחדש על ידי הרצת מנהל הקבצים כ־Administrator (מנהל מערכת). עם החבילה למשתמש הנוכחי בלבד אי אפשר (“⁦Access is denied.⁩”); הריצו שוב את ה־`.msi` ובחרו *Repair* (תיקון).
- **התקנה שקטה או מרחוק ב־⁦Windows 11⁩** (דרך SSH, או מכלי פריסה) מצליחה, אבל הפריט ברמה הראשונה אינו נרשם, ולכן ⁦7-ZSTar⁩ מופיע רק תחת “הצג אפשרויות נוספות”. [פרטים נוספים בהוראות ההתקנה](../install/INSTALL.he.md#תפריט-לחיצה-ימנית-בwindows-11).
- **חילוץ של ⁦tar.br⁩, ⁦tar.lz4⁩, ⁦tar.lz5⁩, ⁦tar.liz⁩ או ⁦tar.Z⁩** עדיין נעשה מבחינתכם בשלב אחד, אבל עובר דרך קובץ זמני שנמחק לאחר מכן.

## דרישות מערכת

נדרש ⁦Windows 7⁩ / ⁦Server 2008 R2⁩ ואילך (⁦x64⁩, ⁦x86⁩), או ⁦Windows 10⁩ ואילך ב־⁦arm64.⁩ אין צורך להתקין שום דבר נוסף. נבדק ב־⁦Windows 7 SP1⁩ של ⁦64⁩ סיביות (עם עדכונים מאוחרים יותר), ב־⁦Windows 10⁩ וב־⁦Windows 11⁩; [מה נבדק](../install/INSTALL.he.md#דרישות-מערכת). ב־Linux יש גרסת שורת פקודה שמרכיבים בעצמכם; macOS אינו נתמך.
