## Почему 7-ZSTar

- **Больше никаких «Показать дополнительные параметры».** В Windows 11 7-ZSTar стоит прямо на первом уровне контекстного меню.
- **tar.zst за один шаг.** Сожмите папку в .tar.zst или извлеките такой архив одним действием, не оставляя на диске .tar. Официальный 7-Zip не умеет создавать .tar.zst, а извлекает его в два шага — через .tar.
- **Примерно в 10 раз быстрее 7z.** На реальных папках проектов tar.zst сжимал в 10–18 раз быстрее.

## Скорость

| Папка | Файлов | Исходный размер | zip | 7z | tar.zst |
|---|---|---|---|---|---|
| Node `node_modules` | 13,371 | 207 MB | 4.1 s / 76.7 MB | 38.4 s / 51.8 MB | **3.8 s** / 59.7 MB |
| Python `.venv` | 9,795 | 346 MB | 6.6 s / 107.8 MB | 54.8 s / 65.7 MB | **3.6 s** / 83.4 MB |
| Python `.venv` (большие бинарные файлы) | 11,654 | 671 MB | 25.5 s / 249.5 MB | 100.8 s / 167.2 MB | **5.6 s** / 210.9 MB |

tar.zst получился на 15–23 % меньше zip и не медленнее. 7z по-прежнему делает самые маленькие файлы (tar.zst был на 15–27 % больше), но работал намного дольше. Извлечение заняло примерно одинаковое время во всех трёх случаях.

Для всех трёх — параметры по умолчанию; 7-ZSTar 26.05.1 x64, Intel Core Ultra 7 155H, NVMe SSD, медиана трёх запусков, 2026-11.

## Форматы

- **Сжатие за один шаг:** tar.zst, tar.br, tar.lz4, tar.lz5, tar.liz, tar.gz, tar.bz2, tar.xz
- **Извлечение за один шаг:** все перечисленные, а также tar.lzma и tar.Z
- **Добавленные кодеки:** zstd, brotli, lz4, lz5 и lizard (сами по себе или внутри .7z), а также fast-lzma2 — альтернативный кодировщик LZMA2
- Все форматы, которые поддерживает официальный 7-Zip, по-прежнему работают.

## Скачать

Большинству подойдёт `.msi` для всех пользователей (x64) со страницы [Релизы](https://github.com/7zStar/7-ZSTar/releases/latest).

| | `.msi` для всех пользователей | Только для вас `-user.msi` | Портативный `.zip` |
|---|---|---|---|
| Нужны права администратора | Да | Нет | Нет |
| Контекстное меню | Первый уровень в Windows 11 | Классическое меню (в Windows 11 — под «Показать дополнительные параметры») | Нет |
| Меню "Пуск" (ярлык) | Да | Да | Нет |

Каждый вариант есть и для x86, и для arm64; выберите тот, что соответствует вашей Windows. В 64-разрядной Windows в пакетах x86 контекстного меню может не быть, а сборки для arm64 пока не проверялись на реальном оборудовании. 7-ZSTar устанавливается рядом с официальным 7-Zip и никак на него не влияет.

**При первом запуске Windows может выдать предупреждение.** Файлы не подписаны цифровой подписью, поэтому SmartScreen может их остановить («Система Windows защитила ваш компьютер»; чтобы увидеть кнопку *Выполнить в любом случае*, возможно, придётся развернуть предупреждение), а в Windows 11, где включено «Интеллектуальное управление приложениями», `.msi` блокируется полностью. К каждому релизу прилагается файл `SHA256SUMS`, с которым можно сверить скачанный файл. [Инструкция по установке](../install/INSTALL.ru.md#неподписанные-пакеты-smartscreen-и-интеллектуальное-управление-приложениями) объясняет, как это сделать и что делать, если включено «Интеллектуальное управление приложениями».

**О меню на первом уровне:** в Windows 11 `.msi` для всех пользователей добавляет небольшой пакет, подписанный самоподписанным сертификатом, и доверяет этому сертификату; именно это требуется Windows для первого уровня. При удалении убираются оба. Если вам это не нужно, установите командой `msiexec /i 7-ZSTar-<version>-<arch>.msi SPARSE=0`. Пакет регистрируется для учётной записи, запустившей установщик; другие учётные записи регистрируют его отдельно.

Ассоциации файлов, удаление и пакет для отдельного пользователя описаны в [инструкции по установке](../install/INSTALL.ru.md).

## Командная строка

```
7z a -ttar.zst backup.tar.zst docs
7z x backup.tar.zst -oout
```

В PowerShell возьмите параметр в кавычки: `7z a "-ttar.zst" backup.tar.zst docs`. Без кавычек PowerShell разобьёт его надвое, и вы получите файл с именем `.zst`. В Command Prompt (cmd) — командной строке Windows — кавычки не нужны.

## Что полезно знать

- **Если отключить «Встроить 7-ZSTar в контекстное меню оболочки»** (файловый менеджер, **Сервис > Настройки > 7-ZSTar**), пункт в контекстном меню пропадёт, как и в официальном 7-Zip. С пакетом для всех пользователей включить его обратно можно, запустив файловый менеджер через «Запуск от имени администратора». С пакетом для отдельного пользователя так не получится («Отказано в доступе.»); запустите `.msi` ещё раз и выберите *Repair* (восстановление).
- **Тихая или удалённая установка в Windows 11** (по SSH или из средства развёртывания) проходит успешно, но пункт на первом уровне не регистрируется, поэтому 7-ZSTar виден только под «Показать дополнительные параметры». [Подробнее в инструкции по установке](../install/INSTALL.ru.md#контекстное-меню-windows-11).
- **Извлечение tar.br, tar.lz4, tar.lz5, tar.liz или tar.Z** для вас по-прежнему один шаг, но проходит через временный файл, который потом удаляется.

## Системные требования

Windows 7 / Server 2008 R2 или новее (x64, x86) либо Windows 10 или новее на arm64. Больше ничего устанавливать не нужно. Проверено на 64-разрядной Windows 7 SP1 (с установленными последующими обновлениями), Windows 10 и Windows 11; [что именно проверялось](../install/INSTALL.ru.md#системные-требования). Для Linux есть консольная сборка, которую нужно собирать самостоятельно; macOS не поддерживается.
