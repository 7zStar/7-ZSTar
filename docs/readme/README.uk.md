**Форк 7-Zip, зручніший для користувачів сучасної Windows 11: перший рівень контекстного меню, стиснення zstd і tar.zst за один прохід.**

[Завантажити](https://github.com/7zStar/7-ZSTar/releases/latest) · [Вебсайт](https://www.7zstar.com) · [Список змін](../../CHANGELOG.md)

## Чому 7-ZSTar

- **Більше жодного «Показати додаткові параметри».** У Windows 11 7-ZSTar розташований прямо на першому рівні контекстного меню.
- **tar.zst за один крок.** Стиснути теку в .tar.zst або розпакувати його можна одним кроком, без жодного .tar на диску. Офіційний 7-Zip не вміє створювати .tar.zst, а розпаковує його у два кроки — через .tar.
- **Приблизно в 10 разів швидше, ніж 7z.** На реальних теках проєктів tar.zst стискався в 10–18 разів швидше.

## Швидкість

| Тека | Файлів | Вихідний розмір | zip | 7z | tar.zst |
|---|---|---|---|---|---|
| Node `node_modules` | 13,371 | 207 MB | 4.1 s / 76.7 MB | 38.4 s / 51.8 MB | **3.8 s** / 59.7 MB |
| Python `.venv` | 9,795 | 346 MB | 6.6 s / 107.8 MB | 54.8 s / 65.7 MB | **3.6 s** / 83.4 MB |
| Python `.venv` (великі бінарні файли) | 11,654 | 671 MB | 25.5 s / 249.5 MB | 100.8 s / 167.2 MB | **5.6 s** / 210.9 MB |

tar.zst вийшов на 15–23 % меншим за zip і не повільнішим. Найменші файли, як і раніше, дає 7z (tar.zst був на 15–27 % більшим), але на це йшло значно більше часу. Розпаковування в усіх трьох випадках зайняло приблизно однаково.

Усі три — з параметрами за замовчуванням; 7-ZSTar 26.05.1 x64, Intel Core Ultra 7 155H, NVMe SSD, медіана з 3 запусків, 2026-11.

## Формати

- **Стиснення за один крок:** tar.zst, tar.br, tar.lz4, tar.lz5, tar.liz, tar.gz, tar.bz2, tar.xz
- **Розпаковування за один крок:** усі перелічені вище, а також tar.lzma і tar.Z
- **Додані кодеки:** zstd, brotli, lz4, lz5 і lizard (окремо або всередині .7z), а також fast-lzma2 — альтернативний кодувальник LZMA2
- Усі формати, з якими працює офіційний 7-Zip, як і раніше підтримуються.

## Завантаження

Більшості людей потрібен `.msi` для всіх користувачів, x64, зі сторінки [Releases](https://github.com/7zStar/7-ZSTar/releases/latest).

| | `.msi` для всіх користувачів | `-user.msi` лише для вас | Портативний `.zip` |
|---|---|---|---|
| Потрібні права адміністратора | Так | Ні | Ні |
| Контекстне меню | Перший рівень у Windows 11 | Класичне меню (у Windows 11 — у «Показати додаткові параметри») | Немає |
| Запис у Меню "Пуск" | Так | Так | Ні |

Кожен із них є також для x86 і arm64; виберіть той, що відповідає вашій Windows. У 64-розрядній Windows пакети x86 можуть не мати контекстного меню, а збірки arm64 ще не пробували на реальному обладнанні. 7-ZSTar встановлюється поруч з офіційним 7-Zip і не впливає на нього.

**Під час першого запуску Windows може показати попередження.** Файли не мають підпису коду, тому SmartScreen може їх зупинити («ОС Windows захистила цей ПК»; можливо, доведеться розгорнути попередження, щоб побачити *Виконати*), а в Windows 11 з увімкненою функцією «Інтелектуальне керування програмами» `.msi` блокується повністю. До кожного випуску додається файл `SHA256SUMS`, за яким можна перевірити завантажене. Як це зробити і що робити, коли ввімкнено «Інтелектуальне керування програмами», пояснено в [посібнику зі встановлення](../install/INSTALL.uk.md#непідписані-пакети-smartscreen-та-інтелектуальне-керування-програмами).

**Про меню першого рівня:** у Windows 11 `.msi` для всіх користувачів додає невеликий пакет, підписаний самопідписаним сертифікатом, і довіряє цьому сертифікату; саме цього Windows вимагає для першого рівня. Видалення прибирає обидва. Якщо ви цього не хочете, встановіть програму командою `msiexec /i 7-ZSTar-<version>-<arch>.msi SPARSE=0`. Пакет реєструється для облікового запису, який запускає інсталятор; інші облікові записи реєструють його окремо.

Асоціації файлів, видалення та пакет для окремого користувача описано в [посібнику зі встановлення](../install/INSTALL.uk.md).

## Командний рядок

```
7z a -ttar.zst backup.tar.zst docs
7z x backup.tar.zst -oout
```

У PowerShell параметр потрібно взяти в лапки: `7z a "-ttar.zst" backup.tar.zst docs`. Без них PowerShell розбиває його надвоє, і ви отримуєте файл під назвою `.zst`. Командний рядок (cmd) лапок не потребує.

## Варто знати

- **Вимкнення «Інтегрувати 7-ZSTar до контекстного меню оболонки»** (файловий менеджер, **Інструменти > Налаштування... > 7-ZSTar**) прибирає пункт із контекстного меню, як в офіційному 7-Zip. З пакетом для всіх користувачів його можна ввімкнути знову, запустивши файловий менеджер з правами адміністратора. З пакетом для окремого користувача так зробити не можна («Access is denied.»); запустіть `.msi` ще раз і виберіть *Repair* (відновлення).
- **Тихе або віддалене встановлення у Windows 11** (через SSH або з інструмента розгортання) завершується успішно, але пункт першого рівня не реєструється, тож 7-ZSTar з'являється лише в «Показати додаткові параметри». [Докладніше в посібнику зі встановлення](../install/INSTALL.uk.md#контекстне-меню-windows-11).
- **Розпаковування tar.br, tar.lz4, tar.lz5, tar.liz або tar.Z** для вас так само відбувається за один крок, але проходить через тимчасовий файл, який потім видаляється.

## Системні вимоги

Windows 7 / Server 2008 R2 або новіша (x64, x86), чи Windows 10 або новіша на arm64. Більше нічого встановлювати не потрібно. Перевірено на 64-розрядних Windows 7 SP1 (з установленими пізнішими оновленнями), Windows 10 і Windows 11; [що саме перевірялося](../install/INSTALL.uk.md#системні-вимоги). У Linux є збірка для командного рядка, яку ви компілюєте самостійно; macOS не підтримується.
