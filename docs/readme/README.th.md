## ทำไมต้อง 7-ZSTar

- **ไม่ต้องกด “แสดงตัวเลือกเพิ่มเติม” อีกต่อไป** บน Windows 11 7-ZSTar อยู่ในเมนูคลิกขวาระดับแรกเลย
- **tar.zst ในขั้นตอนเดียว** จะบีบอัดโฟลเดอร์เป็น .tar.zst หรือแตกไฟล์ .tar.zst ก็ทำได้ในขั้นตอนเดียว โดยไม่มีไฟล์ .tar ค้างอยู่บนดิสก์ 7-Zip ฉบับทางการสร้าง .tar.zst ไม่ได้ และแตกไฟล์ .tar.zst ต้องทำสองขั้นตอน โดยผ่าน .tar
- **เร็วกว่า 7z ประมาณ 10 เท่า** จากโฟลเดอร์โปรเจกต์จริง tar.zst บีบอัดเสร็จเร็วกว่า 7z 10 ถึง 18 เท่า

## ความเร็ว

| โฟลเดอร์ | จำนวนไฟล์ | ขนาดต้นฉบับ | zip | 7z | tar.zst |
|---|---|---|---|---|---|
| Node `node_modules` | 13,371 | 207 MB | 4.1 วินาที / 76.7 MB | 38.4 วินาที / 51.8 MB | **3.8 วินาที** / 59.7 MB |
| Python `.venv` | 9,795 | 346 MB | 6.6 วินาที / 107.8 MB | 54.8 วินาที / 65.7 MB | **3.6 วินาที** / 83.4 MB |
| Python `.venv` (ไบนารีขนาดใหญ่) | 11,654 | 671 MB | 25.5 วินาที / 249.5 MB | 100.8 วินาที / 167.2 MB | **5.6 วินาที** / 210.9 MB |

ไฟล์ tar.zst เล็กกว่า zip 15 ถึง 23% และไม่ช้ากว่า ส่วน 7z ยังได้ไฟล์เล็กที่สุด (tar.zst ใหญ่กว่า 15 ถึง 27%) แต่ใช้เวลานานกว่ามาก การแตกไฟล์ใช้เวลาพอ ๆ กันทั้งสามรูปแบบ

ใช้ค่าเริ่มต้นทั้งสามรูปแบบ 7-ZSTar 26.05.1 x64, Intel Core Ultra 7 155H, NVMe SSD, ค่ามัธยฐานจากการทดสอบ 3 รอบ 2026-11

## รูปแบบที่รองรับ

- **บีบอัดในขั้นตอนเดียว:** tar.zst, tar.br, tar.lz4, tar.lz5, tar.liz, tar.gz, tar.bz2, tar.xz
- **แตกไฟล์ในขั้นตอนเดียว:** ทั้งหมดข้างต้น รวมถึง tar.lzma และ tar.Z
- **ตัวเข้ารหัสที่เพิ่มเข้ามา:** zstd, brotli, lz4, lz5 และ lizard (ใช้เดี่ยว ๆ หรือใช้ภายใน .7z ก็ได้) รวมถึง fast-lzma2 ซึ่งเป็นตัวเข้ารหัส LZMA2 อีกแบบหนึ่ง
- ทุกรูปแบบที่ 7-Zip ฉบับทางการรองรับ ยังใช้งานได้เหมือนเดิม

## ดาวน์โหลด

คนส่วนใหญ่ต้องการ `.msi` x64 แบบผู้ใช้ทุกคน จาก [รีลีส](https://github.com/7zStar/7-ZSTar/releases/latest)

| | `.msi` แบบผู้ใช้ทุกคน | `-user.msi` แบบเฉพาะคุณ | `.zip` แบบพกพา |
|---|---|---|---|
| ต้องใช้สิทธิ์ผู้ดูแล | ต้อง | ไม่ต้อง | ไม่ต้อง |
| เมนูคลิกขวา | ระดับแรกบน Windows 11 | เมนูแบบคลาสสิก (บน Windows 11 อยู่ใต้ “แสดงตัวเลือกเพิ่มเติม”) | ไม่มี |
| รายการในเมนูเริ่ม | มี | มี | ไม่มี |

แต่ละแบบมีให้สำหรับ x86 และ arm64 ด้วย เลือกให้ตรงกับ Windows ของคุณ บน Windows 64 บิต แพ็กเกจ x86 อาจไม่มีเมนูคลิกขวา และรุ่น arm64 ยังไม่เคยลองบนเครื่องจริง 7-ZSTar ติดตั้งควบคู่กับ 7-Zip ฉบับทางการได้โดยไม่กระทบกัน

**Windows อาจแสดงคำเตือนในครั้งแรก** ไฟล์เหล่านี้ไม่ได้ลงนามโค้ด SmartScreen จึงอาจหยุดไว้ (“Windows ให้การปกป้องพีซีของคุณแล้ว” คุณอาจต้องขยายคำเตือนก่อนจึงจะเห็น “ยืนยันการเรียกใช้”) และบน Windows 11 ที่เปิดการควบคุมแอปแบบอัจฉริยะ (Smart App Control) ไว้ `.msi` จะถูกบล็อกทันที ทุกรีลีสมีไฟล์ `SHA256SUMS` ไว้ให้ตรวจสอบไฟล์ที่ดาวน์โหลด [วิธีตรวจสอบ และสิ่งที่ต้องทำเมื่อเจอการควบคุมแอปแบบอัจฉริยะ อยู่ในเอกสารการติดตั้ง](../install/INSTALL.th.md#แพ็กเกจที่ไม่มีลายเซ็น-smartscreen-และการควบคุมแอปแบบอัจฉริยะ)

**เกี่ยวกับเมนูระดับแรก:** บน Windows 11 `.msi` แบบผู้ใช้ทุกคนจะเพิ่มแพ็กเกจขนาดเล็กที่ลงนามด้วยใบรับรองที่ลงนามด้วยตัวเอง และเชื่อถือใบรับรองนั้น ซึ่งเป็นสิ่งที่ Windows กำหนดไว้สำหรับเมนูระดับแรก การถอนการติดตั้งจะนำออกทั้งสองอย่าง หากไม่ต้องการ ให้ติดตั้งด้วย `msiexec /i 7-ZSTar-<version>-<arch>.msi SPARSE=0` แพ็กเกจนี้ลงทะเบียนให้บัญชีที่รันตัวติดตั้ง ส่วนบัญชีอื่นต้องลงทะเบียนแยกกัน

เรื่องการเชื่อมโยงไฟล์ การถอนการติดตั้ง และแพ็กเกจแบบเฉพาะผู้ใช้ อยู่ใน [เอกสารการติดตั้ง](../install/INSTALL.th.md)

## บรรทัดคำสั่ง

```
7z a -ttar.zst backup.tar.zst docs
7z x backup.tar.zst -oout
```

ใน PowerShell ให้ใส่เครื่องหมายอัญประกาศครอบสวิตช์: `7z a "-ttar.zst" backup.tar.zst docs` ถ้าไม่ใส่ PowerShell จะแยกมันออกเป็นสองส่วน และคุณจะได้ไฟล์ชื่อ `.zst` ส่วน Command Prompt (cmd) ไม่ต้องใส่

## ควรรู้

- **การปิด “รวบรวมคำสั่ง 7-ZSTar ไปที่แถบเมนูลัด”** (ในตัวจัดการไฟล์ ที่ **เครื่องมือ > ตัวเลือก > 7-ZSTar**) จะเอารายการในเมนูคลิกขวาออก เหมือนใน 7-Zip ฉบับทางการ กับแพ็กเกจแบบผู้ใช้ทุกคน ให้เปิดกลับด้วยการรันตัวจัดการไฟล์ในฐานะผู้ดูแล ส่วนแพ็กเกจแบบเฉพาะผู้ใช้ทำแบบนั้นไม่ได้ (จะขึ้น “Access is denied.”) ให้รัน `.msi` อีกครั้งแล้วเลือก *Repair* (ซ่อมแซม)
- **การติดตั้งแบบเงียบหรือจากระยะไกลบน Windows 11** (ผ่าน SSH หรือจากเครื่องมือติดตั้งใช้งาน) ติดตั้งสำเร็จ แต่จะไม่ลงทะเบียนรายการระดับแรก 7-ZSTar จึงปรากฏเฉพาะใต้ “แสดงตัวเลือกเพิ่มเติม” [รายละเอียดเพิ่มเติมอยู่ในเอกสารการติดตั้ง](../install/INSTALL.th.md#เมนูคลิกขวาของ-windows-11)
- **การแตกไฟล์ tar.br, tar.lz4, tar.lz5, tar.liz หรือ tar.Z** สำหรับคุณยังคงเป็นขั้นตอนเดียว แต่ระหว่างทำจะผ่านไฟล์ชั่วคราวซึ่งจะถูกลบทิ้งในภายหลัง

## ข้อกำหนดของระบบ

Windows 7 / Server 2008 R2 ขึ้นไป (x64, x86) หรือ Windows 10 ขึ้นไปสำหรับ arm64 ไม่ต้องติดตั้งอะไรเพิ่ม ทดสอบแล้วบน Windows 7 SP1 แบบ 64 บิต (ที่ติดตั้งอัปเดตรุ่นหลังแล้ว), Windows 10 และ Windows 11 [สิ่งที่ได้ทดสอบ](../install/INSTALL.th.md#ข้อกำหนดของระบบ) บน Linux มีรุ่นบรรทัดคำสั่งที่คุณต้องคอมไพล์เอง ส่วน macOS ไม่รองรับ

## เอกสารประกอบ

**ช่วยเหลือ > เนื้อหาและดัชนี** และ F1 จะเปิด `7-zip.chm` ซึ่งเป็นไฟล์วิธีใช้ของ 7-Zip ฉบับทางการ ไฟล์นั้นเขียนว่า “7-Zip” ตลอด และไม่ครอบคลุมสิ่งที่ 7-ZSTar เพิ่มเข้ามา ส่วนนั้นให้ดูหน้านี้และ [บันทึกการเปลี่ยนแปลง](../../CHANGELOG.md) หากไม่พบไฟล์วิธีใช้ รายการเดียวกันจะเปิดหัวข้อนี้ทางออนไลน์แทน
