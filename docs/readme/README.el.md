## Γιατί 7-ZSTar

- **Τέλος στο «Εμφάνιση περισσότερων επιλογών».** Στα Windows 11, το 7-ZSTar βρίσκεται ακριβώς στο πρώτο επίπεδο του μενού δεξιού κλικ.
- **tar.zst με ένα βήμα.** Συμπιέστε έναν φάκελο σε .tar.zst ή εξαγάγετέ τον με ένα μόνο βήμα, χωρίς να μένει .tar στον δίσκο. Το επίσημο 7-Zip δεν μπορεί να δημιουργήσει .tar.zst και το εξάγει σε δύο βήματα, μέσω ενός .tar.
- **Περίπου 10× ταχύτερα από το 7z.** Σε πραγματικούς φακέλους project, η συμπίεση σε tar.zst ήταν 10 έως 18 φορές ταχύτερη.

## Ταχύτητα

| Φάκελος | Αρχεία | Αρχικό μέγεθος | zip | 7z | tar.zst |
|---|---|---|---|---|---|
| Node `node_modules` | 13,371 | 207 MB | 4.1 s / 76.7 MB | 38.4 s / 51.8 MB | **3.8 s** / 59.7 MB |
| Python `.venv` | 9,795 | 346 MB | 6.6 s / 107.8 MB | 54.8 s / 65.7 MB | **3.6 s** / 83.4 MB |
| Python `.venv` (μεγάλα δυαδικά αρχεία) | 11,654 | 671 MB | 25.5 s / 249.5 MB | 100.8 s / 167.2 MB | **5.6 s** / 210.9 MB |

Το tar.zst προέκυψε 15 έως 23% μικρότερο από το zip, χωρίς να είναι πιο αργό. Το 7z εξακολουθεί να δίνει τα μικρότερα αρχεία (το tar.zst ήταν 15 έως 27% μεγαλύτερο), αλλά χρειάστηκε πολύ περισσότερο χρόνο. Η εξαγωγή κράτησε περίπου τον ίδιο χρόνο και με τις τρεις μορφές.

Προεπιλεγμένες ρυθμίσεις και για τις τρεις· 7-ZSTar 26.05.1 x64, Intel Core Ultra 7 155H, NVMe SSD, διάμεσος 3 εκτελέσεων, 2026-11.

## Μορφές

- **Συμπίεση με ένα βήμα:** tar.zst, tar.br, tar.lz4, tar.lz5, tar.liz, tar.gz, tar.bz2, tar.xz
- **Εξαγωγή με ένα βήμα:** όλες οι παραπάνω, καθώς και tar.lzma και tar.Z
- **Πρόσθετοι κωδικοποιητές:** zstd, brotli, lz4, lz5 και lizard (μόνοι τους ή μέσα σε .7z), καθώς και fast-lzma2, ένας εναλλακτικός κωδικοποιητής LZMA2
- Όλες οι μορφές που χειρίζεται το επίσημο 7-Zip εξακολουθούν να λειτουργούν.

## Λήψη

Οι περισσότεροι χρήστες χρειάζονται το `.msi` x64 για όλους τους χρήστες από τις [Εκδόσεις](https://github.com/7zStar/7-ZSTar/releases/latest).

| | `.msi` για όλους τους χρήστες | `-user.msi` μόνο για εσάς | Φορητό `.zip` |
|---|---|---|---|
| Απαιτεί δικαιώματα διαχειριστή | Ναι | Όχι | Όχι |
| Μενού δεξιού κλικ | Πρώτο επίπεδο στα Windows 11 | Κλασικό μενού (στα Windows 11, κάτω από το «Εμφάνιση περισσότερων επιλογών») | Κανένα |
| Καταχώριση στο Μενού "Έναρξη" | Ναι | Ναι | Όχι |

Καθένα διατίθεται και για x86 και arm64· διαλέξτε αυτό που ταιριάζει με τα Windows σας. Σε 64-bit Windows, τα πακέτα x86 μπορεί να μην έχουν μενού δεξιού κλικ, και οι εκδόσεις arm64 δεν έχουν δοκιμαστεί ακόμη σε πραγματικό υλικό. Το 7-ZSTar εγκαθίσταται δίπλα στο επίσημο 7-Zip χωρίς να το επηρεάζει.

**Τα Windows μπορεί να σας προειδοποιήσουν την πρώτη φορά.** Τα αρχεία δεν φέρουν ψηφιακή υπογραφή κώδικα, οπότε το SmartScreen μπορεί να τα σταματήσει («Τα Windows προστάτευσαν τον υπολογιστή σας»· ίσως χρειαστεί να αναπτύξετε την προειδοποίηση για να δείτε το *Εκτέλεση*), και στα Windows 11 με το «Έξυπνος έλεγχος εφαρμογών» ενεργό, το `.msi` αποκλείεται εντελώς. Κάθε έκδοση περιλαμβάνει ένα αρχείο `SHA256SUMS`, με το οποίο μπορείτε να ελέγξετε τη λήψη σας. Ο [οδηγός εγκατάστασης](../install/INSTALL.el.md#μη-υπογεγραμμένα-πακέτα-smartscreen-και-smart-app-control) εξηγεί πώς, και τι να κάνετε με τον Έξυπνο έλεγχο εφαρμογών.

**Για το μενού πρώτου επιπέδου:** στα Windows 11, το `.msi` για όλους τους χρήστες προσθέτει ένα μικρό πακέτο υπογεγραμμένο με αυτο-υπογεγραμμένο πιστοποιητικό και εμπιστεύεται αυτό το πιστοποιητικό· αυτό απαιτούν τα Windows για το πρώτο επίπεδο. Η απεγκατάσταση αφαιρεί και τα δύο. Αν προτιμάτε να μην γίνει αυτό, εγκαταστήστε με `msiexec /i 7-ZSTar-<version>-<arch>.msi SPARSE=0`. Το πακέτο καταχωρίζεται για τον λογαριασμό που εκτελεί το πρόγραμμα εγκατάστασης· οι άλλοι λογαριασμοί το καταχωρίζουν ξεχωριστά.

Οι συσχετίσεις αρχείων, η απεγκατάσταση και το πακέτο ανά χρήστη περιγράφονται στον [οδηγό εγκατάστασης](../install/INSTALL.el.md).

## Γραμμή εντολών

```
7z a -ttar.zst backup.tar.zst docs
7z x backup.tar.zst -oout
```

Στο PowerShell, βάλτε τον διακόπτη σε εισαγωγικά: `7z a "-ttar.zst" backup.tar.zst docs`. Χωρίς αυτά, το PowerShell τον χωρίζει σε δύο και καταλήγετε με ένα αρχείο που ονομάζεται `.zst`. Το Command Prompt (cmd) δεν χρειάζεται εισαγωγικά.

## Καλό είναι να γνωρίζετε

- **Η απενεργοποίηση του «Ενσωμάτωση του 7-ZSTar στο λειτουργικό»** (διαχειριστής αρχείων, **Εργαλεία > Ρυθμίσεις > 7-ZSTar**) αφαιρεί την καταχώριση του μενού δεξιού κλικ, όπως και στο επίσημο 7-Zip. Με το πακέτο για όλους τους χρήστες, την ενεργοποιείτε ξανά εκτελώντας τον διαχειριστή αρχείων ως διαχειριστής. Με το πακέτο ανά χρήστη δεν μπορείτε («Δεν επιτρέπεται η πρόσβαση.»)· εκτελέστε ξανά το `.msi` και επιλέξτε *Repair* (επιδιόρθωση).
- **Οι σιωπηλές ή απομακρυσμένες εγκαταστάσεις στα Windows 11** (μέσω SSH ή από εργαλείο ανάπτυξης) ολοκληρώνονται με επιτυχία, αλλά η καταχώριση πρώτου επιπέδου δεν γίνεται, οπότε το 7-ZSTar εμφανίζεται μόνο κάτω από το «Εμφάνιση περισσότερων επιλογών». [Περισσότερα στον οδηγό εγκατάστασης](../install/INSTALL.el.md#μενού-δεξιού-κλικ-των-windows-11).
- **Η εξαγωγή tar.br, tar.lz4, tar.lz5, tar.liz ή tar.Z** εξακολουθεί να είναι ένα βήμα για εσάς, αλλά περνά από ένα προσωρινό αρχείο που διαγράφεται στη συνέχεια.

## Απαιτήσεις συστήματος

Windows 7 / Server 2008 R2 ή νεότερα (x64, x86), ή Windows 10 ή νεότερα σε arm64. Δεν χρειάζεται να εγκαταστήσετε τίποτα άλλο. Έχει δοκιμαστεί σε 64-bit Windows 7 SP1 (με εγκατεστημένες τις μεταγενέστερες ενημερώσεις), Windows 10 και Windows 11· [τι δοκιμάστηκε](../install/INSTALL.el.md#απαιτήσεις-συστήματος). Στο Linux υπάρχει μια έκδοση γραμμής εντολών που τη μεταγλωττίζετε μόνοι σας· το macOS δεν υποστηρίζεται.

## Τεκμηρίωση

Το **Βοήθεια > Περιεχόμενα** και το F1 ανοίγουν το `7-zip.chm`, το αρχείο βοήθειας του επίσημου 7-Zip. Αναφέρει παντού «7-Zip» και δεν καλύπτει ό,τι προσθέτει το 7-ZSTar· αυτά τα καλύπτουν αυτή η σελίδα και το [αρχείο αλλαγών](../../CHANGELOG.md). Αν λείπει το αρχείο βοήθειας, οι ίδιες καταχωρίσεις ανοίγουν αυτή την ενότητα στο διαδίκτυο.

Για να μεταγλωττίσετε μόνοι σας το 7-ZSTar, δείτε το [build/README.md](../../build/README.md)· πριν από τη συγχώνευση μιας νέας έκδοσης του upstream, διαβάστε το [MAINTAINING.md](../../MAINTAINING.md).

## Δωρεά

Το 7-ZSTar χρησιμοποιείται δωρεάν, είτε κάνετε δωρεά είτε όχι. Αν σας έχει εξοικονομήσει χρόνο και θέλετε να πείτε ένα ευχαριστώ, μπορείτε να στείλετε κρυπτονομίσματα στην παρακάτω διεύθυνση. Τα χρήματα πηγαίνουν σε εμένα, τον DraftingDreamer, για τα δικά μου έξοδα ανάπτυξης και δεν εξασφαλίζουν λειτουργίες, βοήθεια ή οποιαδήποτε δέσμευση για το τι θα ακολουθήσει.

Δεκτό είναι οποιοδήποτε token στο Ethereum ή στο Polygon: ETH, POL, USDT, USDC ή οτιδήποτε άλλο. Η διεύθυνση είναι η ίδια και στα δύο δίκτυα.

```
0x6c60bFCaDfb3AD63eC6D821baB0E6323361BFD4f
```
